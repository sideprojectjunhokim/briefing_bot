## Deviations 로그

- **2026-07-15 — 채널 텔레그램 → 웹 (C-2 → C-2′).** 유저가 "웹으로 간단하게" 선택. 봇 웹훅 함수·grammY·메시지 포맷 계층 전부 제거, briefing-job은 발송 대신 briefings INSERT. 04 문서 재작성(bot-ux → web-ux), 01/02/05 반영. 보수적 선택: 푸시 상실은 PWA 백로그로 남겨 되돌릴 수 있게 함.
- **2026-07-28 — 하루 1회 → 시간당, 그리고 정량 폐기 (C-1 → C-1′, C-8 → C-8′, +C-12~C-19).**
  용도가 "아침에 한 번"에서 "일하는 중 한 시간마다"로 바뀌면서 수집 주기만 바꾸면 실패한다는 게 분명해졌다 — 한가한 시간엔 채울 게 없어 잡글이 들어가기 때문이다. 그래서 제품의 단위 자체를 "안 읽은 큐"로 바꿨다.
  인프라도 같이 갈렸다: Supabase 무료 활성 2개를 이미 다 써서 신규 생성이 막혔고, Vercel Cron Hobby는 하루 1회가 상한, Cloudflare 계정은 회사 것이다. 개인 계정으로 시간당이 되는 무료 수단이 GitHub Actions뿐이라 시계를 거기로 옮기고 수집 코드를 Next.js 안으로 들였다.
  **폐기:** `supabase/` 전체(배포·실행된 적 없음), `FolderStack`·`FilePage` 컴포넌트, `briefings.skipped_empty` 행 생성.
  **보수적 선택:** market은 template 렌더를 유지해 숫자에 LLM을 대지 않았고(D-9로 남김), 아카이브 재출고·건너뛰기 알림·하루 끝 한 장은 임계값을 보수적으로 둬 며칠 뒤 조정 가능하게 했다.
