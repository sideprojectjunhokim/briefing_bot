# 04. 웹 UX — 대시보드

> 07-15 피벗으로 봇 명령어 UX(구 04)를 웹 대시보드로 대체.

## 페이지 구조 (단일 페이지 `/`)

```
┌───────────────────────────────────────────────┐
│  📰 오늘의 브리핑        7/15 (수)   [새로고침]   │  ← 헤더: 날짜 + 재조회
│  ⚠ community 수집 실패 (에펨 차단)               │  ← failed 있을 때만 배너
├───────────────────────────────────────────────┤
│  ┌─ 🔥 핫딜 ──────────── 08:01 ─┐               │
│  │ · 품목/가격/한줄평 …           │  모듈 카드    │
│  │ · …                           │  (모듈별 최신) │
│  └───────────────────────────────┘               │
│  ┌─ 📈 시세 ──────────── 08:00 ─┐               │
│  │ 코인 · BTC … / 지수 · KOSPI … │               │
│  └───────────────────────────────┘               │
│  ┌─ 👨‍💻 테크 ─────────── 08:02 ─┐               │
│  ┌─ 💬 커뮤니티 ───────── 08:03 ─┐               │
├───────────────────────────────────────────────┤
│  ⚙ 표시 모듈:  [🔥][📈][👨‍💻][💬]  ← 토글(localStorage) │
└───────────────────────────────────────────────┘
```

- **모듈당 카드 1개**, 모듈별 최신 briefings 1행. status='ok'만 카드로.
- 카드 헤더에 모듈 라벨 + 생성 시각(KST). 본문은 briefings.content(HTML/마크다운) 렌더.
- 빈 모듈(skipped_empty)은 "오늘 새 소식 없음" 흐린 카드 or 숨김(설정). 기본: 숨김.
- `failed` 모듈은 상단 배너 한 줄.

## 상호작용

| 요소 | 동작 | Phase |
|------|------|-------|
| 새로고침 | supabase-js로 briefings 재조회(수집 아님) | 1 |
| 모듈 토글 | localStorage에 on/off 저장, 카드 표시/숨김 | 2 |
| 카드 "더보기" | 해당 모듈 과거 브리핑 목록(페이지네이션) | 백로그 |
| 온디맨드 수집 | 보호된 트리거로 briefing-job 호출 | 백로그(토큰 필요) |

- v1은 **읽기 전용**이 원칙. 수집은 cron이 하고 웹은 본다. 온디맨드 수집은 JOB_SECRET을 브라우저에 못 두므로 별도 보호 장치 마련 후(백로그).

## 렌더링/데이터

- Next.js App Router. 홈은 **ISR(revalidate 짧게, 예: 300s)** 또는 클라이언트 fetch — 최신 briefings 반영.
- supabase-js anon 클라이언트, 쿼리: 모듈별 `select ... where module_key=? order by created_at desc limit 1`. (뷰 `latest_briefings`로 감싸면 1쿼리로.)
- content는 신뢰된 소스(우리 Edge Function 생성)라 sanitize 후 dangerouslySetInnerHTML 또는 마크다운 렌더. **LLM 출력이므로 sanitize 필수**(XSS 방지: 허용 태그 화이트리스트).

## 톤·스타일

개인 도구. 다크 기본, 카드 밀도 높게, 모바일 뷰(폰에서 아침에 봄) 우선 반응형. 마케팅 문구·과한 이모지 없이 위 예시처럼 건조하게.
